# School ERP System

نظام ERP مالي ومدرسي مبني على **Odoo 19 Community**، ومهيأ للعمل باللغة
العربية وللبيئة المحاسبية في المملكة العربية السعودية.

## الموديولات

- `school_finance`: الطلاب وأولياء الأمور، الرسوم والأقساط، دفعات إنشاء
  الفواتير، الموافقات، لوحة المؤشرات، وضوابط المستندات المالية.
- `custom_web_app_launcher`: مشغل تطبيقات مخصص لواجهة Odoo.
- `acc_reports_enterprise` و`accounting_pdf_reports`: التقارير المالية
  وطباعتها وتصديرها.
- موديولات Odoo Mates للمحاسبة والأصول والموازنات والسنة المالية والمتابعة
  والتقارير اليومية والدفعات المتكررة.

## التشغيل

يتطلب المشروع Docker مع Docker Compose. أنشئ ملفات التشغيل المحلية من
القوالب ثم استبدل القيم الافتراضية بكلمات مرور قوية ومتطابقة:

```bash
cp .env.example .env
cp config/odoo.conf.example config/odoo.conf
cp docker-compose.example.yml docker-compose.yml
docker compose up -d
```

تعمل واجهة Odoo افتراضيًا على:

```text
http://127.0.0.1:8169
```

بعد بدء Odoo، حدّث قائمة التطبيقات وثبّت `school_finance`. يعتمد الموديول
على موديولات المحاسبة والتوطين السعودي المذكورة في ملف
`addons/school_finance/__manifest__.py`.

## البيانات الحساسة

لا يحتوي المستودع على قاعدة PostgreSQL، أو Odoo filestore، أو النسخ
الاحتياطية، أو إعدادات الخادم الفعلية. هذه البيانات مستبعدة عمدًا من Git.
احتفظ بنسخها الاحتياطية في تخزين آمن خارج المستودع.
